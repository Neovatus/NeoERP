## Findings
1. Step 4 — **A recurring journal in Draft mode can't be saved with a blank amount**, which is the point of Draft mode ("Amounts filled in each time"). The app sends a blank-amount line without a side (RecurringMapper.toBody: "a blank amount of a DRAFT template keeps no side"), but the server requires `side` on every line (RecurringBodies.line: `text("side", required = true)`, comment "C-14: every line has an account and a side; the amount may be blank"). Result: 400 "Invalid request fields"; the screen shows only "Check the fields and try again." App and backend contracts disagree.
