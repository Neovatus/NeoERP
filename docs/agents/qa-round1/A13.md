## Data checks
- DB `journal_imports` (newest first): good.csv DISCARDED by Anna Lindh (15:23 check); good.csv DISCARDED by **Bjorn Eriksson** (Anna's 15:19 check); good.csv DISCARDED by Anna (A12); fixed.csv CONFIRMED; problems.csv DISCARDED; good.csv CONFIRMED. Drafts at Kystgruppe stay 7; nothing posted.
- Backend rule (read for the report): `JournalImportService.discard` lets anyone holding JOURNAL_REJECT discard another person's check (`createdBy != caller && !holds(JOURNAL_REJECT) → notYours`). So this is a deliberate backend choice that the script/spec ("no Discard for Bjørn"; "this discards only your own check") don't describe.

## Findings
1. Steps 3–4 — **a Finance Manager (Bjørn) and an Owner (Ola) can discard another person's checked import.** The read-only view offers Discard, and the server accepts it (discarded_by Bjorn Eriksson). The uploader isn't told: her open Check page only fails at Create with "This check was discarded. Nothing was created." and history still shows her name under By. Expected by the script: no Discard for anyone but the uploader. If the backend rule (JOURNAL_REJECT may discard) is intended, the spec, the script and the uploader's message need to say who discarded it. Severity: flow (no money moves, but someone's work is thrown away silently). iPad mini landscape (Bjørn), iPad Pro 13 portrait (Ola). Screenshot: A13-step3-readonly-discard-ipadmini.png. Time: 15:22
2. Step 7 — coming back to Import journals does not resume the person's own unfinished check; it always opens a fresh Upload step, so a checked file is easy to forget (and counts against the 5-checked-files limit, `IMPORT_QUEUE_FULL`). Reachable only via Earlier imports. Severity: flow. iPhone 18 Pro portrait. Screenshot: A13-step7-no-resume-iphone.png. Time: 15:25
3. Step 4 — after a check is discarded by someone else, the uploader's page shows "This check was discarded. Nothing was created." and an empty card with no next action (no Upload again / Earlier imports button). Severity: flow (minor). iPhone 18 Pro portrait. Time: 15:23
