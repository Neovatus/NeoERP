## 1. Decided already
- Change = new version, future only, approved again; posted periods, kind, source never change; old version runs until approved (spec R-6, A4 C-16).
- Writers cumulative over all versions; no writer approves any step of any version; no stand-in for a writer (Fable c6).
- Change banded on the **larger** of old and new remaining (Fable c7; spec R-10 says "new remaining": spec text to align, c7 wins).
- End early: reason 6–500; LEAVE = no journal, no second person; POST_REST = one journal in a chosen open period, approved as a change (spec R-7, §4.3, SP-1).
- Post again / Post in next open period: actor holds SPREADING.APPROVE and is no writer; Owner only via 4.11 switch, `ownerSelfApproval` (Fable c1). Alternative allowed: journal waits to post with writers as contributors.
- Pause: any APPROVE or JOURNAL.REVERSE holder, reason, no second person; Resume needs a non-writer APPROVE holder (Fable c5). Pause/resume add no writer (A4 C-4, Fable allocations c1 by analogy).
- Closed/locked period: never re-dated by the job; waits + Needs you; person picks next open period or reopens (SP-6, R-5, c10). A LOCKED period is final (409 PERIOD_STATE, FL-10): only "move" applies.
- Move (run 0) waiting: releases wait until it posts, then catch up in date order (FL-6).
- One live journal per schedule and run; attempt number for Post again; key `SPR:{id}:{n}:{attempt}`; End/change/job serialise on the schedule row; invariant posted live + remaining = approved (c9).
- Feature off: approved schedules keep posting; no create, submit, approve, change, move, post again (SP-8, c11). FINANCE off / not LIVE: job skips, catches up later (c11).
- Period close row: count **and amount** not posted for the period, never blocking (spec §4.6, c10). Reconciliation line per balance account (§4.6; D-90 Q2 says period-end reconciliation is flow 2).
- Dimension fix after a FAILED run: logged change, new approval only if amount or accounts change; job never drops or fills (D-91 G4, D-82).
- Audit: CHANGE_PROPOSE (before/after), CHANGE_APPROVE, END, POST_AGAIN, MOVE, PAUSE, RESUME with actor + reason (spec §11, c13). Versions, snapshots, runs never hard-deleted ≥10 y (D-90).
- Notification R-15 stays backlog (D-90 Q4). Source credited never changes a schedule by itself: "Source credited" + Needs you (R-8).

## 3. Size estimate (rough, from flow 1's 6.5k/4.4k BE and 7.1k/3.6k App)
